# Checklist Travelogue

- [ ] Fonti canoniche indicate nei metadati.
- [ ] Nessuna informazione DM-only in testi per giocatori.
- [ ] Nessuna teoria trasformata in fatto.
- [ ] POV dichiarato e coerente.
- [ ] Dialoghi compressi senza cambiare il senso canonico.
- [ ] Scene di combattimento leggibili senza meccaniche.
- [ ] Note di adattamento compilate.
- [ ] Continuita aggiornata se emergono temi, simboli, callback o tratti ricorrenti.
- [ ] Stato travelogue aggiornato.
